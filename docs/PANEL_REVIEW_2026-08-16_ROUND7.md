**Method:** four parallel implementation specialists — design systems, 3D/GPU
performance, build/tooling, accessibility & code quality — each in an isolated
git worktree off round 6's merge (`a2660af`), each assigned a slice of round
6's §3 backlog with disjoint file ownership (`index.css` owned by design
systems; others appended self-contained blocks). Merged sequentially; the full
gate (build + all CI guards, smoke ×9 routes, lint) re-run on the combined

**Result: the entire round-6 deferred backlog (§3 items 1–8) is cleared.**

## 1. What shipped

### Design system (backlog #1–#3)
- **Type scale**: 43 distinct font sizes across 121 declarations → 16
  `--fs-*` tokens (10 static ~7% steps from the 0.68 rem floor, plus fluid
  `--fs-lead` and five `--fs-display-*` clamps; three near-identical display
  clamps merged). 116/121 declarations tokenized, every mapping ≤±0.8 px;
  the three deliberate literals (decorative stage-label dot, in-scene WebGL
  labels) are annotated in-file.
- **Spacing scale**: ~280 hand-typed lengths → 13 `--space-*` steps
  (4–72 px) capped by the pre-existing `--section-pad`, which absorbed the
  96/90/110 px section-pad outliers. Max shift 4 px. Hairlines, optical
  nudges and negative hit-target pairs stay literal, each commented.
- **Rail replumb**: `#main::before` draws the oxide rule once per page —
  continuous through the hero/guarantee/CTA bands where it used to break;
  crash/legal pages stay rail-free. CSS-counter section numerals (`01`,
  `02`…) per the direction doc, placed inside the rail (the doc's outside
  placement clips below ~1330 px — caught by screenshot before commit).
- **Ruled paper**: `.ambient` fixed→absolute; body line-height 1.62→1.6 so
  the 3.2 rem ruling pitch is exactly two body lines.
- No color token or pair changed; §4 tripwires untouched. `404.html` needed
  no re-sync (no token *values* it copies changed).

### 3D/GPU (backlog #4 first half, #5)
- **GPU disposal on row switch**: the single WebGL canvas now lives in a
  stable `.sa-stage-host` element that is *moved* between accordion rows
  (`StageMount`) instead of remounting per row — the previous scene's
  resources no longer accumulate (round 4 had measured +15 textures /
  +17 programs per switch, monotonic).
- **Drawn resting state**: `StageDiagram.jsx` — inline hairline SVG sketches
  (stage ink + dark-palette oxide, aria-hidden, no new deps) shown before a
  scene is engaged, as the permanent stage on constrained devices, and when
  the WebGL chunk fails. "Shown Live" now appears only when a live scene is
  actually mounted; the static label swaps the verify-teal dot for an oxide
  one (teal stays reserved for things genuinely running).

### Build/tooling (backlog #6, #8)
- **Prerender parallelization**: pure `renderRoute()` driven by a worker
  pool capped at 4 (`PRERENDER_CONCURRENCY` overridable); all dist writes
  happen after every route renders, sequentially in original order. Build
  39.2 s → 14.7–19.6 s (~2.4×). Output proven byte-identical to the serial
  baseline by full-tree diff across repeated runs. Failure semantics
  improved: any guard failure aborts the pool and writes *nothing* (the
  serial loop used to have already overwritten earlier routes).
- **`llms.txt` derives from data**: the ₹ band (parsed from
  `pricing.bands`, en-IN notation), founder count (`about.founders.length`),
  service count (`services.length`) and the "about 40 seconds" claim
  (quoted out of `hero.subtitle`, throwing if the claim ever leaves the
  hero) now come from `src/data/content.js` — same source the pages render.
  Generated bytes unchanged. Still hardcoded on purpose: the
  service-enumeration prose, "Kolkata, India", area served, privacy line
  (no lossless single source exists without changing visible copy).

### Accessibility & code quality (backlog #7, #4 second half)
- **Hub table semantics below 720 px**: explicit
  `role="table"/rowgroup/row/columnheader/rowheader/cell"` restoration in
  `ServicesHub.jsx` plus sr-only-clipped `thead` (was `display:none`, which
  deleted all four columnheaders from the AX tree — verified via CDP
  `Accessibility.getFullAXTree` at 390 px, before and after). The visible
  mobile column label moved from `::before` pseudo-content (announced as
  part of the cell value) to a real `aria-hidden` span. Visuals unchanged.
- **"(opens in new tab)"**: new `NewTabHint` component (reuses `.sr-only`)
  on all 20 `target="_blank"` call sites — 14 in the sweep, aria-label
  tails on Footer socials / About LinkedIn icons, and the six
  ServiceExplorer WhatsApp links added post-merge (file was owned by the
  3D agent during the round). `404.html` has no blank-target links.
  WhatsApp FAB and sticky bar already announced it (round 6) — left
  byte-identical to each other.
- **`<PageShell>`**: one page chrome (skip-link/ambient/Navbar/`main`/
  Footer/FAB/sticky bar) replaces the App/ServicePage/ServicesHub
  triplication. All 9 prerendered `<body>` DOMs byte-identical before/after
  (only `<head>` modulepreload lists changed — moved import edges let the
  bundler regroup chunks; entry still 79.x KB gzip against the 84 budget).
